# Campus Bakery POS

A simple JavaScript-based Point-of-Sale system for the IT 415 practical examination.

## Scenario
Campus Bakery POS

Products:
- Pandesal (pack of 5) — ₱25.00
- Ensaymada — ₱20.00
- Spanish Bread — ₱15.00
- Chocolate Cupcake — ₱30.00
- Loaf Bread — ₱55.00
- Brewed Coffee (cup) — ₱25.00

## Features
- Display products and prices
- Add products to cart
- Increase/decrease quantity
- Remove products
- Automatic subtotals and total
- Cash payment input
- Payment validation
- Change calculation
- Payment confirmation
- Digital receipt with transaction reference
- New transaction/reset

## How to run
Open `index.html` in a web browser.

No database or server is required.
